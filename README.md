# VANTA DETAILING

**[Смотреть сайт](https://dr1x-clock.github.io/vanta-detailing-demo/)**

Демонстрационный лендинг вымышленной премиальной детейлинг-студии.

## Что реализовано

- Современный адаптивный дизайн для компьютеров, планшетов и смартфонов.
- Каталог услуг и прайс с демонстрационными ценами.
- Мобильное меню и раскрывающийся раздел частых вопросов.
- Интерактивная форма записи с выбором услуги и проверкой данных.

Форма работает в демонстрационном режиме и не отправляет реальные заявки.

## Технологии

HTML, CSS и JavaScript.
